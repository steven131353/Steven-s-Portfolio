SCRIBBLED

This sketch creates a scribbled typography interaction. As the mouse moves across the canvas, letters from the word “SCRIBBLED” are stamped one by one, leaving messy hand-drawn traces.

SONIC

This sketch visualizes the word “SONIC” as a dynamic wave. The letters react to the mouse position, stretching and distorting as a scanning line moves across them.

BALLS

This project is an interactive billiards-inspired sketch. The user can click and drag to hit letter balls across the table. The letters move with friction, bounce off the walls, and collide with each other, creating a playful word-based physics interaction.
