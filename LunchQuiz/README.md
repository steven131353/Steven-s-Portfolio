# Who Are You in the Overwatch World?

## Project

This is a personality quiz for Project 4: Community Tool or Quiz. The quiz is made for people who enjoy Overwatch's world, animated shorts, character backstories, and ideas about hope, repair, identity, justice, and community.

## Concept

The quiz asks eight questions about the user's values, sense of belonging, response to crisis, personal struggles, and the kind of future they want to help build. It is about personality and story alignment, not in-game combat role.

The result matches the user with one of eight heroes:

- Tracer
- Reinhardt
- Mercy
- Sombra
- Widowmaker
- Lucio
- D.Va
- Genji

## Technical Notes

- Built with HTML, CSS, and vanilla JavaScript.
- Uses radio buttons, a select menu, a range slider, form submission, and click event handlers.
- Stores the user's answers and result in `localStorage`.
- Uses the stored result to change the page background theme and show the previous result when the page is reopened.

## Challenges

The main challenge was translating Overwatch character backgrounds into personality traits without making the quiz feel like a combat-role sorter. I used a point system where each answer adds points to multiple heroes, then the highest score becomes the final result.
