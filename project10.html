Digital Divination

How Will You Ruin Your Life?

p5.js Sketch

Description / Concept

Digital Divination is an interactive p5.js quiz that turns everyday habits into a chaotic fortune-telling experience. The project is designed for students and young creatives who often joke about deadlines, overthinking, burnout, and bad decisions. Instead of giving serious life advice, the quiz uses humor, glitch visuals, and exaggerated "oracle" language to make self-reflection feel playful.

The user answers three open-ended questions. After the final answer, the sketch enters a fake ritual/loading state, then generates a personalized result about how the user might "ruin their life." The tone is intentionally dramatic and sarcastic, but the interaction is really about noticing patterns in daily behavior.

System Logic

The quiz stores each typed response in an answers array. When all questions are finished, the sketch compares the user's words with keyword groups stored in fortunes.json. Each possible result receives a score based on keyword matches. The highest-scoring path becomes the main fortune, with a small random chance of choosing another path to keep the oracle feeling unstable.

The result screen combines three sources: the matched fortune from the local JSON file, a random system glitch message, and one random cat omen from an external data source. The typewriter effect reveals the result one character at a time so the final page feels like a corrupted prediction being printed by the system.

API / Data Used

Local quiz result data: fortunes.json

External API/data source: Corpora Project cats JSON

Design Process

I started with a white-box structure: intro screen, question screen, ritual/loading screen, and final result screen. The first key decision was to use typed input instead of multiple choice, because open answers make the quiz feel more personal and unpredictable. I then connected those answers to simple keyword scoring so the result could still respond to what the user wrote.

The second key decision was the visual style. I used a black-and-red glitch interface, shaking text, random symbols, scan lines, and loading bars to make the quiz feel like a broken digital oracle. For the next version, I would add more questions, more result paths, and a clearer way to show users how their answers influenced the final prediction.
